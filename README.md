# Homebrew tap for Fidelius

```bash
brew install --cask nphardorworse/tap/fidelius
```

[Fidelius](https://fidelius.blisslabs.dev/) keeps your API keys in your Keychain, grouped by project, and runs commands with them through `accio`. Fidelius updates through its own updater (Fidelius > Check for Updates…), so `brew upgrade` skips it.

Bugs and questions: [nphardorworse/fidelius](https://github.com/nphardorworse/fidelius/issues).
